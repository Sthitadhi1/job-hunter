Free · open source · runs on your computer

Upload your resume. Get the jobs most likely to call you back.

job-hunter is an add-on for Claude. You give it your resume and it searches about 15,000 job postings, picks the ones you have the best chance at, finds a real person on LinkedIn at each company, and tells you exactly what to fix in your resume.

Set it up

You need a computer (Windows, Mac or Linux), your resume (PDF or Word), and a Claude plan that includes Claude Code. No coding needed: you'll copy and paste a few lines.

  1. Open a terminal

    Windows: press the Windows key, type PowerShell, press Enter. Mac: press ⌘ Space, type Terminal, press Enter.

  2. Install Claude Code

    Skip this if you already have it. Paste the line for your computer, press Enter, and follow the sign-in prompt.

    irm https://claude.ai/install.ps1 | iex
    curl -fsSL https://claude.ai/install.sh | bash

    This is Anthropic's official installer (setup guide). Close and reopen the terminal afterwards.

  3. Add job-hunter

    Paste these two lines, one at a time:

    claude plugin marketplace add Sthitadhi1/job-hunter#v3.2.0
    claude plugin install job-hunter@job-hunter-marketplace
    Do this yourself rather than asking Claude to install it. Claude deliberately won't install code from a link someone forwarded you. Want to check it first? Read what it does and doesn't do.

  4. Make a folder and start Claude there

    Your results (jobs, contacts, CVs) are saved in this folder.

    mkdir $HOME\Desktop\JobHunt; cd $HOME\Desktop\JobHunt; claude
    mkdir -p ~/Desktop/JobHunt && cd ~/Desktop/JobHunt && claude

    Prefer an app? The Claude desktop app's Code tab works too. Open it, choose the JobHunt folder, and job-hunter is already there.

  5. Run the setup check

    Type this into Claude. It checks everything and offers to install the one free tool it needs (Node.js) if it's missing.

    /job-hunter:setup

  6. Give it your resume

    Drag your resume into the chat (or put it in the JobHunt folder) and type:

    /job-hunter:hunt remote or Bangalore, backend roles

    Or just ask in plain words: "review my resume for AIML jobs", "find me fresher roles in Pune", "who should I message at Swiggy?"

Optional: better LinkedIn contacts

Install Claude in Chrome and stay signed in to LinkedIn in Chrome. job-hunter then reads "Meet the hiring team" and company pages for you. Without it, it finds contacts through web search, which gives fewer of them.

What it will and won't do

WillSearch, rank, find contacts, write drafts, fill application forms, track follow-ups
Won'tSend any message for you · submit an application without your OK · type your passwords · invent experience · upload your resume anywhere

Questions

Will this get me interview calls?

It raises your odds where it counts: applying early to jobs you actually qualify for, with a resume that matches the posting, and reaching a real person instead of only the applicant pool. It can't send the messages, sit the online test or do the interview. Those are yours. People who send the drafted messages and follow up get far more out of it than people who only apply.

Does it cost anything?

job-hunter is free. You need a Claude plan that includes Claude Code. Finding jobs needs no paid API keys. Optional keys (JSearch, Adzuna, Hunter) add more coverage if you have them.

Will my LinkedIn account get in trouble?

It only reads LinkedIn, slowly, and stops at any security check. Automated browsing is still against LinkedIn's rules, so it caps itself at about 40 pages per run. Set linkedin_page_budget to 0 in job-hunt/profile.json to use web search only.

Is my data private?

Everything stays in the JobHunt folder on your computer. The search only sends job titles, skills and locations to job sites, never your resume. No tracking. Delete the folder to remove it all.

Which countries and roles?

Any. It's strongest for tech roles in India, the US and Europe, but works for any job title on your resume (data, design, product, marketing…).

I asked Claude to install it and it refused. Why?

On purpose: Claude won't install code from a source someone forwarded you. Follow step 3 yourself and it takes ten seconds.
